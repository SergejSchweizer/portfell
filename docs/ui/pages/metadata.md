# Metadata Page Specification

## User goal

Filter the all-ISIN universe and create a project.

## Inputs

- exchange
- name substring
- instrument type
- country
- currency
- EODHD credential availability

## Outputs

- project list
- created project selection
- metadata option lists

## Layout regions

- filter form
- project selector
- empty-state guidance
- status copy

## Actions

- fetch all ISINs
- create a new project
- select an existing project
